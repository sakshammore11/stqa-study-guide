# STQA Exam Prep & Study Guide 🚀

An interactive, comprehensive study portal for **Software Testing and Quality Assurance (STQA)**. Designed for college exam preparation with topic breakdowns, interactive quizzes, flashcards, formula cheat sheets, and exam strategies.

## ✨ Features

- 📚 **Comprehensive Coverage**: Unit-by-unit structured revision notes covering Black-box, White-box, Integration, System, Performance, Automation testing, and QA Metrics.
- 🎯 **Interactive Quizzes**: Test knowledge with real-time feedback, explanations, and score tracking.
- 🗂️ **Interactive Flashcards**: Quick spaced-repetition memory cards for key definitions and terminologies.
- 📊 **Visual Diagrams & Tables**: High-yield comparison tables (Verification vs Validation, Alpha vs Beta, White vs Black box).
- 📱 **Fully Responsive & Modern UI**: Sleek dark aesthetic with glassmorphism, fluid typography, and fast performance.

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS** (Custom responsive design system with CSS custom properties)
- **Vanilla JavaScript (ES6+)** (Zero external runtime dependencies)
